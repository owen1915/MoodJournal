# MoodJournal 🧠✨

MoodJournal is a personal, web-based mood tracking app that lets users log how they feel each day using emojis and notes. Over time, it helps users recognize patterns in their emotions and supports emotional awareness.

## 🔧 Features

- Daily mood check-in with emoji + note
- Firestore database integration
- Heatmap of past 30 days of moods
- Pie chart visualization of mood distribution
- AI-generated advice based on your mood
- Excel export of mood history
- Secure user authentication (Firebase)

## 🛠️ Technologies Used

- React (Frontend)
- Firebase Auth & Firestore (Backend)
- Recharts (Charts)
- OpenAI API (Advice)
- XLSX + FileSaver (Export)
